🟢 Step 4: Functions

Function एक reusable block of code होता है। इससे code को बार-बार लिखने की जरूरत नहीं होती।

Function Create करना

Function कैसे बनाते हैं?

# Function Definition

def greet():
    print("Hello Student")

# Function Call

Explanation:

  • def → function define करने के लिए
  • greet() → function का नाम
  • Function call करना जरूरी है
Parameters

Explanation:

  • name → parameter
  • "Ravi" → argument
Return Statement

Explanation:

  • return value वापस देता है
  • return के बाद function समाप्त हो जाता है
Default Argument

  • Default value पहले से set रहती है
  • Argument नहीं देंगे तो default use होगा
Lambda Function

Lambda → Short one-line function

# Normal Function
def square(x):
    return x * x

# Lambda Function

print(square(5))

Explanation:

  • lambda keyword use होता है
  • Single expression only
Recursion

Recursion: Function खुद को call करता है।

# Factorial using Recursion

def factorial(n):

    if n == 1:
        return 1

    return n * factorial(n - 1)

print(factorial(5))

Explanation:

  • Base condition जरूरी है
  • नहीं तो infinite recursion हो जाएगा
  • 5! = 5 × 4 × 3 × 2 × 1

Inheritance
📝 Exam Ready Definition:

Inheritance is a feature where one class acquires properties and methods of another class. It promotes code reusability.

📖 Explanation:
  • Parent class → Base class
  • Child class → Derived class
💻 Code:
# Parent Class
class Animal:
    def speak(self):
        print("Animal speaks")

# Child Class
class Dog(Animal):
    pass

d = Dog()
d.speak()   # Parent method use
🧠 Output:
Animal speaks
📌 Child class parent class की properties use कर सकती है।
Polymorphism & Override
📝 Concept:

Same method name, different behavior.

📖 Explanation:
  • Method overriding → Child class parent method redefine करती है।
💻 Code:
class Animal:
    def sound(self):
        print("Animal sound")

class Dog(Animal):
    def sound(self):   # Override
        print("Bow Bow")

class Cat(Animal):
    def sound(self):
        print("Meow")

animals = [Dog(), Cat()]

for a in animals:
    a.sound()
🧠 Output:
Bow Bow
Meow
📌 Override = Same method name in child class.
Encapsulation
📝 Concept:

Encapsulation data hiding की technique है।

📖 Explanation:
  • Private variable → __variable
  • Getter method से access करते हैं।
💻 Code:
class Bank:
    def __init__(self, balance):
        self.__balance = balance   # Private variable

    def get_balance(self):

b = Bank(5000)

🧠 Output:
5000
📌 Direct access → Error b.__balance ❌

🟢 Step 6: File Handling

open() Function

open() file को खोलने के लिए use होता है।

# Syntax:
file = open("filename.txt", "mode")

# Modes:
# "r"  → Read
# "w"  → Write (पुराना data delete)
# "a"  → Append (data add)
read() Method
# File open in read mode
file = open("student.txt", "r")

# Read complete file
data = file.read()

print(data)

file.close()

read() पूरा content पढ़ता है।

write() & append()
# Write mode (old data delete करेगा)
file = open("student.txt", "w")

file.write("Name: Ravi\n")
file.write("Marks: 85\n")

file.close()


# Append mode (data add करेगा)
file = open("student.txt", "a")

file.write("City: Delhi\n")

file.close()
with Statement

Best Method: Automatically file close करता है।

with open("student.txt", "r") as file:
    data = file.read()
    print(data)

# No need to write file.close()
Text File Complete Example
# Writing Text File

with open("student.txt", "w") as file:
    file.write("Name: Ravi\n")
    file.write("Marks: 85\n")


# Reading Text File

with open("student.txt", "r") as file:
    print(file.read())
CSV File Example
import csv

# Write CSV File
with open("students.csv", "w", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["Name", "Marks"])
    writer.writerow(["Ravi", 85])
    writer.writerow(["Amit", 90])


# Read CSV File
with open("students.csv", "r") as file:
    reader = csv.reader(file)
    for row in reader:
        print(row)

🟢 Step 7: Exception Handling

try Block

try: Risky code यहाँ लिखा जाता है।

try:
    num = int(input("Enter number: "))
    print(10 / num)   # Risky code

except:
    print("Error occurred")
except Block

except: Error को handle करता है।

try:
    x = 10 / 0

except ZeroDivisionError:
    print("Cannot divide by zero!")
finally Block

finally: Always execute होगा (error हो या न हो)

try:
    print("Hello")

except:
    print("Error")

finally:
    print("This always runs")
Multiple except

Different errors के लिए अलग except block.

try:
    num = int(input("Enter number: "))
    result = 10 / num

except ZeroDivisionError:
    print("Division by zero not allowed!")

except ValueError:
    print("Invalid input! Please enter number.")

finally:
    print("Program End")
